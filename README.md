# Font Awesome 7 离线包 + 中文速查手册

Font Awesome Free **7.3.1** 完整离线包，外加一个单文件中文图标速查表和使用教程。
**不联网、不构建、不装 npm** —— 双击 `fa-cheatsheet.html` 就能用。

| | |
|---|---|
| 图标 | **1992** 个（实心 1422 / 品牌 572 / 常规 169），全部免费可用 |
| 分类 | **68** 个官方分类，已翻译成中文 |
| v4 对照 | **810** 条旧类名 → 新类名映射 |
| 依赖 | 零。数据预生成在 `fa-cheatsheet-data.js`，用 `<script>` 加载，不发请求 |

## 为什么做这个

官方文档是英文的、要联网，而且经常卡在"那个像垃圾桶的图标到底叫什么"。
这里把官方 free 包原样保留，在上面叠了一层中文检索，和一份能照着做的中文教程。

## 快速开始

1. clone 或下载本仓库
2. 双击 `fa-cheatsheet.html`，浏览器直接打开即可

> 数据是预生成的 JS（不是 `fetch`），所以 `file://` 方式能正常工作。
> 若要用 VS Code Live Server 打开也可以，但注意两种打开方式的**常用图标互不相通**，见下文。

要在自己的页面里用图标，只要两行：

```html
<link rel="stylesheet" href="css/all.min.css">
<i class="fa-solid fa-house"></i>
```

`webfonts/` 必须和 `css/` 一起部署（`all.min.css` 里按 `../webfonts/` 找字体），只拷 CSS 图标会显示成方块 □。

## 图标库视图

### 搜索

顶部搜索框支持这些写法，可以混着搜：

- **英文类名**：`house`、`envelope`
- **官方关键词**：`arrow`、`upload`
- **v4 旧类名 / 别名**：`envelope-o`、`dashboard`
- **Unicode 码点**：`f015`，也认 `&#xf015;`、`0xf015`、`\uf015`、`u+f015`
- **中文分类名**：`箭头`、`商务办公`（按分类匹配，不是逐个图标的中文名）

结果按匹配精度排序：类名精确命中 > 码点命中 > 旧版名精确命中（方便迁移时找对应关系）> 名称前缀 > 关键词 > 分类。
输入即时出结果，无延迟、无请求。

### 筛选与浏览

- 风格切换：**全部 / 实心 Solid / 常规 Regular / 品牌 Brands**
- 左侧分类栏：68 个中文分类 + 全部分类 + 常用图标，每项带图标数量
- 图标卡片：显示类名和 Unicode 码点

### 卡片上的两个按钮

- **星标**：加入 / 移出常用图标
- **复制**：一键复制该图标的完整 `<i class="...">` HTML

### 图标详情

点卡片（或键盘 `Enter`）打开详情，里面给全：

- 各风格并排预览 + 对应类名
- **旧版名称** chips，点击直接跳转搜索
- **所属分类** chips，点击直接筛选该分类
- **代码片段**，每条可单独复制：
  - HTML · 实心 / 常规 / 品牌（按该图标实际支持的风格）
  - CSS `::before`（自动带正确的 `font-family` 和 `font-weight`）
  - HTML 实体 `&#xNNNN;`
  - **FA7 新增的 `--fa` 变量写法**（品牌图标不提供此项）
- 尺寸效果：1x / 2x / 3x 实机渲染

### 快捷键

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `Esc` | 清空搜索词 / 关闭详情弹窗 |
| `Enter` | 打开当前聚焦卡片的详情 |
| `Tab` | 在卡片间移动（卡片可聚焦） |

复制功能优先用 `navigator.clipboard`，不可用时自动降级到 `execCommand`，
所以 `file://` 下也能正常复制。

## 常用图标

看到合适的图标，点卡片右上角的**星标**就加入常用（再点一次移出），详情弹窗里也有同一个按钮。

- 侧栏顶部的「**常用图标**」是独立视图，只看收藏的那些，同样受风格筛选影响
- 在「全部分类」下且没有输入搜索词时，常用图标会以「常用」分组**置顶**在网格开头
- 数据存在浏览器 `localStorage`（键名 `fa-favs`），**纯本地，不连任何数据库或服务**

### 一个必须知道的坑

`localStorage` 按「浏览器 + 打开方式」隔离：

- **双击打开**（`file://`）和 **Live Server**（`http://127.0.0.1:5500`）是两份独立存储，互不相通
- 换浏览器、换电脑也不通
- 清理浏览器网站数据会把它一起清掉

所以「常用图标」视图右上角有**导出 / 导入**：导出把数据以 `FA-FAVS:[...]` 形式复制到剪贴板，
到目标浏览器粘贴进「导入」即可恢复；导入是**合并去重**，不会覆盖已有收藏。
攒了一套顺手的图标建议导出一份存着。

升级 Font Awesome 版本后，新数据里已不存在的图标名会在加载时自动从常用中剔除，不会留下空位。

## 目录结构

| 路径 | 说明 |
|---|---|
| `css/` `scss/` `js/` | 官方编译产物（CSS / SCSS 源码 / JS） |
| `webfonts/` | 字体文件，**必须和 `css/` 一起部署**，否则图标变方块 |
| `svgs/` `svgs-full/` | 官方 SVG（按风格分目录） |
| `sprites/` `sprites-full/` | 官方雪碧图 |
| `metadata/` | 官方图标元数据，速查页的数据源 |
| `fa-cheatsheet.html` | 速查表 + 教程（本仓库新增，单文件） |
| `fa-cheatsheet-data.js` | 由脚本生成的数据，**不要手改** |
| `fa-cheatsheet-build.py` | 生成上面那个数据文件的脚本 |

## 升级到新版本

1. 用新版官方包里的 `metadata/` 覆盖本仓库的 `metadata/`
2. 运行 `python3 fa-cheatsheet-build.py`
3. 刷新 `fa-cheatsheet.html`，数据自动更新

脚本会打印版本号、各风格图标数、分类数和生成文件大小，方便确认没跑错。
只需要 Python 3 标准库，无需安装依赖。
